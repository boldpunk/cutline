# Как устроен «поиск» на alteg.io/ru/pricing — разбор с доказательствами

Дата наблюдения: 19.10.2026. Метод: страница открыта в Chromium (Playwright) через прокси песочницы; сохранены HTML после отрисовки, сетевые запросы, консоль, снимки экрана; встроенные скрипты прочитаны статически. Каждое утверждение ниже помечено: **наблюдение** (видели своими глазами/в логах), **вывод** (следует из кода или наблюдений), **неизвестно**.

Ограничение среды: домен `alteg.io` был разрешён, а `api.alteg.io` — нет. Поэтому запросы страницы к API тарифов в нашем окружении не прошли (E8); всё, что зависит от ответа API, помечено как неизвестное.

## Короткий ответ

На странице тарифов нет поиска в привычном смысле (нет поля ввода). Под словом «поиск» там две разные вещи:

1. **Пункт «Поиск» с бейджем «Cmd K» в выпадающих меню навигации.** Это обычная ссылка на стандартный поиск WordPress `/ru/?s=`. Сочетание клавиш при нашем наблюдении ничего не открывало, а страница результатов по трём запросам показала только «Не найдено» (E2–E5).
2. **Калькулятор тарифа** — главный интерактивный блок: выбор размера команды, переключатель промокода, четыре карточки периодов. Страна определяется автоматически, цены приходят из API Altegio по стране (E6–E8).

## Выводы

- «Поиск» на странице тарифов — это ссылка на поиск сайта WordPress. Бейдж «Cmd K» обещает палитру команд, но в наблюдаемой версии она не подключена (E2–E4), а страница результатов пустая (E5).
- Калькулятор целиком клиентский: страна → запрос цен → перерисовка карточек; размер команды выбирает уже загруженную строку тарифов (E7). Пересчёт с промокодом идёт без сети (E8).

## Неизвестно

- Что возвращает API тарифов для разных размеров команды и стран и как меняются цифры по кнопкам — нужен доступ к `api.alteg.io`.
- Почему промо «−30%» даёт 4 280 → 3 042 (≈ −28,9%): без ответа API формулу не проверить.
- Работает ли поиск сайта для других запросов и языков; проверены три русских запроса.

## Что из этого взято для CUTLINE (своя реализация, не копия)

Скопированы не код и не вёрстка, а идея «поиск открывается откуда угодно по Cmd/Ctrl+K». Сделано так, чтобы обещание бейджа действительно выполнялось, и под русскоязычного клиента:

- Палитра поиска по `Cmd/Ctrl+K` и `/` на любой публичной странице, кнопка «Поиск» в шапке (она же ссылка на `/search`, поэтому работает и без JavaScript).
- Ищет по живым данным: услуги (с ценой и длительностью), мастера, ответы на частые вопросы (адрес и часы, перенос и отмена, цены, данные). Результат сразу ведёт в нужный шаг записи.
- Понимает запросы, на которых обычный поиск отвечает «Не найдено»: начало слова («стриж»), опечатку («барода»), английскую раскладку («cnhb;rf» → «стрижка»), латиницу («timur», «boroda»).
- Пустой результат подсказывает, куда идти, вместо голого «Не найдено».
- Индекс публичный и маленький, без данных клиентов; поиск выполняется в браузере мгновенно.
