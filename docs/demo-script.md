# Как показать CUTLINE барберу — сценарий на 7 минут

Сайт: **https://cutline-p5nw.onrender.com**

**За 2 минуты до встречи** откройте сайт: бесплатный Render засыпает без посетителей, и первое открытие занимает до минуты. Демо-салон пересобирается при каждом запуске сервера: свежие записи на ближайшие дни, всё, что меняли гости, стирается.

## 1. Глазами клиента (3 минуты)

1. Главная → блок **«Демо за две минуты»** → **«Открыть страницу салона»**.
2. Пролистайте страницу: прайс, **Работы** (портфолио), **Мастера** с уровнями (барбер, топ, бренд), **Что есть в салоне** (кофе, PlayStation, детское кресло…).
3. **Записаться** → «Стрижка + борода» → мастер **Алишер**. Обратите внимание: у бренд-барбера своя цена, клиент видит её до записи.
4. Выберите день (точка = есть свободное время) и время → имя и любой телефон → подтвердите.
5. На экране: номер записи, PIN и личная ссылка. По ней клиент сам переносит или отменяет запись — без звонка.

Фишка для разговора: **занятое время выбрать невозможно** — даже если два человека жмут одновременно.

## 2. Глазами барбера (3 минуты)

1. Главная → **«Войти как администратор»** (без пароля).
2. **Календарь** → «Сегодня» / «Неделя»: только что созданная запись уже здесь.
3. **Новая запись** — если клиент позвонил или зашёл с улицы.
4. **Блокировки** — обед, отпуск: на это время онлайн записаться нельзя.
5. **Работы** — загрузить фото стрижки, оно сразу появится на странице.
6. **Настройки** → «Стиль страницы»: переключите на **«Латунь»** и откройте страницу салона — другой вид за секунду. Там же отметьте удобства.

Можно выйти и войти **«Как мастер»**: мастер видит только свои записи.

## 3. Как начать (1 минута)

- «Твоя страница — **/start**, 15 минут: название, адрес `morki`, услуги, график, публикация».
- Ссылку — в шапку Instagram и в закреп «Запись».
- Пошаговая презентация для него уже готова.
